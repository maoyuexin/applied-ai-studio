# 02 · From Data to Decision: How an AI System Is Built

What AI can and cannot do, and the anatomy of any AI system: **task, data modality, learning
paradigm and model class**. A card-fraud model is then built in the five stages every later lesson
reuses: Data Ingestion, Feature Engineering, Model Training, Model Validation and Model Prediction.
The lesson closes with ten business scenarios to classify the same way.
