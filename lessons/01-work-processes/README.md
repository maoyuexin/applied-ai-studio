# 01 · How Work Happens, and Where AI Fits

Every AI application sits inside a business process. This lesson maps one process as
**Inputs → Process → Decision → Action → Outcome**, finds the decisions inside it, judges
which of them AI actually fits, and designs the survivors with **Data → Model → Metric → Human**.
The running case is one online order, ending with the payment-screening decision.
