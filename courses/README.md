# Courses

A course maps its own modules and schedule to the shared [lesson library](../lessons/README.md).
Keep course logistics (dates, assignments, grading) here, not in the lessons, so other courses can
reuse the lessons unchanged.

| Course | Institution | Map |
|---|---|---|
| ITAI 2372 · Artificial Intelligence Applications | Houston Community College, Fall 2026 | [itai-2372](itai-2372/README.md) |

To add a course, create `courses/<course-id>/README.md` with a module-to-lesson table.
